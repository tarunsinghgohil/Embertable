# Brief 03 QA and Integration Lane

Own `test/`, evidence, and integration branch only. Do not modify business behavior to make tests pass. Add black-box tests for cross-tenant reads/writes/notifications, staff denial, wrong-manager denial, missing role, DST ambiguity/clarification, idempotency, and failure/retry. Run the full suite after each merge. Escalate any mismatch with the client brief with reproduction steps and expected safe behavior.
